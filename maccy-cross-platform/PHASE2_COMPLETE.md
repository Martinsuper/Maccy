## 🎨 功能演示

### 1. 粘贴模拟（Play 按钮）

**操作流程：**
```
1. 在 Maccy 中查看历史记录
2. 点击绿色 Play 按钮 ▶️
3. 等待 100ms
4. 自动执行 Cmd+V
5. 内容粘贴到原应用
```

**使用场景：**
- 快速粘贴多个内容
- 保持工作流不中断
- 无需手动切换窗口

### 2. 固定功能（Pin 按钮）

**操作流程：**
```
1. 找到重要的历史记录
2. 点击黄色 Pin 按钮 📌
3. 该项被标记为固定
4. 自动移到顶部显示
5. 带有黄色高亮背景
```

**使用场景：**
- 固定常用代码片段
- 保留重要链接
- 快速访问频繁使用的文本

### 3. 分区显示

**UI 结构：**
```
┌─────────────────────────┐
│ 📌 PINNED (固定区)      │
│ - 固定项显示在这里       │
│ - 黄色背景高亮          │
│ - 不会被自动清理         │
├─────────────────────────┤
│ RECENT (最近区)         │
│ - 普通历史记录           │
│ - 按时间排序            │
│ - 可能被自动清理         │
└─────────────────────────┘
```
